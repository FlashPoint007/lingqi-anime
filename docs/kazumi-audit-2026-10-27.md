# Kazumi 上游与本站全面对照（2026-10-27）

本站基线 v111。读取官方最近 5 个 release、main 最近 50 个提交、主目录结构、播放器设置、API 规则模型与执行器，以及 KazumiRules 当前有效索引和全部 17 个规则文件。判断依据为已合并源码；测试中构造的 API 响应不等于第三方服务在线验收。

## 上游是否有新版本

- 最新正式版仍为 [2.4.2](https://github.com/Predidit/Kazumi/releases/tag/2.4.2)，2026-10-23 发布，修复部分地区规则仓库访问。
- main 当前核对到 [`57d13399`](https://github.com/Predidit/Kazumi/commit/57d13399df3f34641a1b3100822671e8c545cf30)。正式版后的提交为 Linux Debian 包依赖、项目结构/README/贡献文档和 Flutter 3.47.8 更新，没有新增 Web 播放功能。
- KazumiRules 当前提交 [`09725452`](https://github.com/Predidit/KazumiRules/commit/0972545266e7ac7cc06e7e522892239824f7d713)，有效规则 17 条；其中 [giriGiriLove 2.6](https://github.com/Predidit/KazumiRules/blob/0972545266e7ac7cc06e7e522892239824f7d713/giriGiriLove.json) 改为 API 搜索、API 分集和分隔字符串格式。不是新的 Kazumi App 版本，但会影响本站现有片源。

## 发现并修复的实际缺口

### API 规则已同步，解析器却未完整支持

v111 已保存 giriGiriLove 2.6，但 `apiChapters()` 仅实现嵌套 JSON，并假设每个规则都有 `episodePage.url`。对该规则的 `vod_play_from` / `vod_play_url` 直接返回空目录。云浏览器在芙莉莲详情复现“giriGiriLove：同名条目未解析到分集”。不能把这个错误归为源站没有资源。

本次按上游 [API 执行器](https://github.com/Predidit/Kazumi/blob/57d13399df3f34641a1b3100822671e8c545cf30/lib/services/plugin/api_rule_strategy.dart) 和[规则模型](https://github.com/Predidit/Kazumi/blob/57d13399df3f34641a1b3100822671e8c545cf30/lib/plugins/api_rule_config.dart) 补齐：

- 分隔格式的多线路、线路名称、分集名称和地址。只按第一个字段分隔符拆开名称与 URL，保留 URL 内后续 `$` 字符。
- 没有播放页模板时直接读取条目 URL；支持相对页面地址、CDN 视频直链，以及空 `roadsPath` 的单线路响应。
- 模板支持从零计数的索引和从一计数的 `roadNumber` / `episodeNumber`；保留稀饭源已有线路代码。
- 受限 JSONPath 支持带引号的字段名；仍拒绝递归、表达式、过滤器、切片和函数，不执行规则脚本。
- POST 表单与显式 `bodyType: none`；已有 JSON 请求保持兼容。
- 限制路径长度、匹配数量、线路数和分集数；忽略非法或私网播放地址，不因一个坏条目丢弃整条有效线路。

### CDN 直链的播放、续播和下载衔接

原 `/api/source` 仅接受与规则同源的播放页面，即使视频 URL 来自源站自己的 API 目录也会拒绝。现在只有重新读取所选规则目录、找到完全一致的媒体条目后，才允许该 CDN 地址进入现有连接检查与站内签名媒体服务。目录外地址、缺失目录身份、外站 HTML 页面和私网地址仍拒绝；没有改成通用任意 URL 代理。

观看记录还会把源站目录中的 `.mp4` / `.m3u8` 当成自定义直链，绕过原规则并丢失规则身份。现在携带源站目录及规则名的记录仍走规则核验；原规则被移除或停用时寻找同集其他源。普通自定义视频直链维持现有行为。

来源解析缓存增加解析器版本，避免继续命中旧的空目录。本机启动用的规则快照也按同一上游提交的 17 个文件完整更新；D1 全局规则同步机制保持独立于个人登录。

## 逐项功能结论

| 上游模块或行为 | 本站情况与是否需要修改 |
| --- | --- |
| 热门、分类、分页、高级搜索、快捷语法 | 已有服务端分页与条件校验，支持日期/评分/排名/标签/星期/编号和标题别名。原生 UI 不直接迁移。 |
| 季度放送与排除已看/弃番 | 已对齐季度范围；当前周历包含跨季连载，历史季度为首播档案。数量随上游更新，不固定旧日期的数量。 |
| 规则自动更新、镜像 | 已有 D1 全站共享、有效索引同步、完整快照核验与镜像恢复；这次修复“规则存在但格式不支持”的缺口。 |
| API 8/9 搜索、详情模板和分集 | 之前仅部分实现，本次补齐上面列出的分隔格式与请求/模板语义。不能据此保证未来所有新 API 格式都受支持。 |
| 进度拖动预览、串行跳转 | 已有；上游 10 月 20 日改动已适配。 |
| 倍速、快捷键、长按、手势、音量静音记忆 | 已有，设备限制仍由浏览器决定。 |
| 自动恢复、连播、定时暂停、隐身 | 已有；恢复开关在 v109 补齐，v110 改善换集失败的自动恢复。 |
| 控制栏自动隐藏时长、任意视频比例 | 尚未逐项对齐。本站主要控制条位于视频下方，直接隐藏会改变网页操作布局；作为独立播放器体验改动评估，不能只复制一个无效开关。已有完整/裁切/拉伸/4:3。 |
| 禁用动画 | 已尊重系统 `prefers-reduced-motion`；尚无独立播放器开关，不把系统行为说成完全相同的上游设置。 |
| 低内存、错误日志、超分、画中画、投屏 | 已有 Web 适配；浏览器解码与系统接口不等于原生任意解码器、DLNA 或全平台后台播放。 |
| 弹幕自动抓取、来源切换、导入、屏蔽/简繁/偏移 | 已有；外部服务仍受可用性和本站授权凭证影响。屏蔽偏好可经本站账号/D1 同步。 |
| 弹幕发送与编辑时暂停 | 已有本站账号发送、预览、本人撤回及编辑暂停；发送到本站，不冒充向外部服务投稿。 |
| 弹幕手动关键词检索及按番剧检索历史 | 尚未实现上游完整关键词检索流程；本站提供自动匹配、来源链接和文件导入。应在服务授权与准确匹配方案齐备后单独实现，不能仅加一段无结果的搜索 UI。 |
| 截图候选、全选、导出 | 已有；原生文件系统和图片库授权不直接搬到网页。 |
| VTT/SRT、音轨/内嵌字幕 | 已有本地 VTT/SRT 与可用 HLS/原生轨道选择；完整 ASS/SSA 字体与排版渲染尚缺，需独立性能/兼容验证。 |
| 下载、任务管理、分片续传和进度 | 已有浏览器文件下载、站内 IndexedDB 离线库、HLS 分片复用及校验后的 MP4 Range 续传；v111 修复跨集/账号/线路的旧回调污染。 |
| 下载弹幕、HLS 广告过滤 | 尚未与原生下载包完整对齐。现有离线库保存视频；没有把不支持的广告过滤或离线弹幕声明为已完成。 |
| 追番五状态、逐集记录、检索与布局 | 已有本站邮箱账号与 D1 同步、冲突处理、离线待同步队列和备份。统计只覆盖保留记录，不虚构累计时长。 |
| Bangumi OAuth、评分、吐槽、外部收藏同步 | 未接入。适合后续独立建设，需要本站 OAuth 应用、回调、令牌保护及双向冲突策略；本站邮箱账号不是 Bangumi 账号。 |
| WebDAV | 未实现；本站已有 D1 和备份。需独立处理跨域、凭证和原生数据格式兼容，不自动部署保存用户外部凭证的界面。 |
| SyncPlay 一起看 | 未实现；需要适合 Web 的房间服务、权限与同步协议，不直接搬原生 TCP 客户端。 |
| 原生系统代理、ECH、解码器、安装包升级和 iOS 路径迁移 | 不直接适用托管网页。网页使用官方 HTTPS 镜像、浏览器媒体能力及部署更新，不宣称实现同等原生接口。 |

## 验证范围

`scripts/check-api-rule-parity.cjs` 先复现旧解析器空目录、缺失模板异常、受限路径不兼容，以及历史续播绕过规则的问题；修复后执行真实解析器、当前规则快照及生产 `/api/source` 和续播入口，验证正常目录、嵌套/分隔格式、请求模板、CDN 目录成员校验、私网/外站 HTML/伪造媒体拒绝。既有全部回归、TypeScript 和正式构建继续执行。第三方实时结果另以云浏览器记录，代码检查不代表所有 17 个源均可播放。
