# 下载续传、分享与个人工具（2026-10-22）

## 站内离线下载

- 单集保存与批量任务均支持站内离线库；最多 100 个记录，每批最多 50 集，单集最多 1 GB。Web Lock 保证多个标签页只有一个媒体写入者。队列在本站页面内继续运行，离开放映室不影响保存；关闭网站会暂停，重新打开后可继续。
- 传输模块使用新的版本路径，避免已安装旧 Service Worker 的浏览器读取旧模块而缺少续传接口。每个 2 MB 块和资产偏移在一个 IndexedDB 事务中提交。普通视频仅在 strong ETag 或 Last-Modified、总长度、206 范围和原始地址全部一致时追加；不支持续传的源站会安全地重新读取文件。
- HLS 保留完整分片与初始化文件，三路并发补齐缺失项。重新获取播放授权后，只去掉本站媒体包装中变化的授权信息来比较源地址，源站查询参数一律保留。清晰度、完整列表和引用地址的 SHA-256 不一致时拒绝拼接，用户可明确选择重新下载。
- 展示实际接收字节、平均接收速度和完整分片数。未知文件总量不伪造百分比；HLS 百分比按完整分片数计算。浏览器原生文件下载的进度仍由浏览器提供。
- 失败时等待所有写入者结束，仅删除不完整 HLS 资产。暂停保留已提交的普通视频块；删除与重启在下载锁内执行，并验证个人空间。媒体仅在设备 IndexedDB，不写 D1/R2。

## 分享与排除已看

- `#subject/<id>` 可在无观看记录的设备直接打开番剧详情；原有 `#watch/<id>` 无本机记录时也会打开详情。不会携带源站地址或播放授权，不会为收件人自动开始播放。
- `#search?...` 保存关键词、类型、年份、排序、页码、高级条件及排除开关。刷新、浏览器返回与前进均读取经过验证的路由。`#calendar?year=...&quarter=...&day=...` 保留放送季度与星期。
- 搜索和时间表可独立排除收藏状态中的“已看完”和“已弃番”。分享链接只包含开关，收件人使用自己的收藏状态。
- 搜索按完整源页取数，每批最多扫描三页补齐结果，下一批从未扫描过的源页继续，不跳过可见条目。只显示原目录总数，不把未计算的个人排除总数当作精确结果数；时间表的每日数量按实际筛选更新。

## 弹幕高级屏蔽与 D1 同步

- 关键词、最多 32 条正则（每条 64 字符）、最长长度、连续相同字符刷屏、来源、模式、重复合并与显示偏好共同过滤，支持 JSON 导入导出。
- RE2JS 2.8.6 使用线性匹配，编译后的程序规模限制为 512。无效规则会显示错误而不执行；不使用 JavaScript 回溯正则执行用户表达式。
- 通过 `/api/library?version=3` 的 `danmaku:0` 记录同步，沿用账号、CSRF、版本比较、幂等确认和持久待上传队列。旧 v1/v2 客户端不会收到它们不支持的新记录。匿名使用本机空间；登录后迁移，切换账号隔离；旧的全局偏好只迁移给升级时确认的旧空间。
- 弹幕模块及正则引擎在进入播放器后按需加载，不增加首页首屏脚本。不同步弹幕文件、视频、字幕或截图。

## 截图候选

- 播放器按钮与截图快捷键将原始 PNG 帧放入候选区，切换分集保留。可全选、取消、逐张勾选、删除；单张直接保存 PNG，多张用现有 ZIP32 实现打包，浏览器保存一个文件。
- 上限 24 张、总计 32 MB。离开放映室、切换番剧或账号时释放 Object URL；截图不进入数据库。直连视频未开放画面读取时提供“启用截图读取并重连”，由用户明确触发，保留进度与暂停状态；源站拒绝跨域时恢复普通播放。截图失败不会自行重载视频。

导航与搜索在首次路由恢复提交后启用；导航序号使旧渲染的 URL 同步失效。路由标记先于 History 操作更新，兼容同步派发事件的框架，避免恢复链接覆盖用户新选择。

## 回归

`check-offline.cjs` 验证 HLS 断点重用、播放列表变化保护、重新载入后的 MP4 字节一致性、锁、账户隔离、Service Worker Range 和旧进度确认。

`check-six-features.cjs` 验证分享条件往返及真实根路由、筛选分页不漏片、线性正则和输入界限、截图 ZIP CRC、容量限制和账号切换清理。

`check-library.cjs` 与 `check-library-hook.cjs` 验证实际 SQLite/D1 语句、旧协议兼容、偏好冲突、账号切换及离线待上传重放。另运行已有播放、规则、安全、目录和浏览器下载回归以及 TypeScript、生产构建。
