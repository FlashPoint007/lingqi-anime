# 邮箱验证与密码找回

本次增加邮箱验证注册、旧账号补验邮箱、密码找回及安全确认页。邮件通过 Resend 的 HTTPS API 发送，兼容 Cloudflare Workers，无需 SMTP 或浏览器插件。

## 配置

在 Sites 的生产运行环境变量中配置，设置后部署新版本使配置生效：

| 变量 | 用途 | 类型 |
| --- | --- | --- |
| `RESEND_API_KEY` | Resend Sending access 密钥，建议限制到发件域名 | Secret |
| `LINGQI_MAIL_FROM` | 已通过 Resend 域名验证的发件地址，例如 `零柒番剧 <accounts@example.com>` | 环境变量 |
| `LINGQI_SITE_URL` | 邮件回跳的固定 HTTPS 站点根地址 | 环境变量 |
| `LINGQI_AUTH_SECRET` | 已有密码 pepper，继续保留原值 | Secret |

站点已配置 `LINGQI_SITE_URL=https://lingqi-anime.bonnycarp9.chatgpt.site`。截至本次修改，生产环境尚无 `RESEND_API_KEY` 和 `LINGQI_MAIL_FROM`，实际投递尚未启用。不能用 Resend 的测试发件域名替代正式发件域名向公众发送邮件；发件域名可以独立于当前网站域名。

在 Resend 验证你持有域名的发送能力，按其控制台提供的 DNS 记录配置。验证/恢复邮件应关闭链接及打开跟踪，避免第三方跟踪链路处理恢复凭证。不要提交密钥、验证链接或用户密码到 GitHub、浏览器存储或日志。

配置缺失时，页面明确提示邮箱服务尚未就绪；已有账号的登录与个人记录同步保持可用。新注册、补验邮件、找回邮件入口禁止发起请求，服务器同样拒绝未经配置的发信操作，避免假装发送成功或创建未经验证的账号。

## 用户流程

- 新注册：输入邮箱 → 请求注册验证邮件 → 从邮件打开确认页 → 设置并确认密码 → 验证并完成注册 → 返回首页登录。验证前不占用账号或保存密码，注册链接不会覆盖已有账号。
- 旧账号：继续原密码登录，在个人同步栏选择“验证邮箱”。只向当前邮箱会话的所属地址发送补验邮件；请求体中的其他地址不能改变收件人。
- 找回：登录窗口选择“忘记密码？” → 输入邮箱 → 从邮件打开重置页 → 设置并确认新密码 → 返回首页重新登录。重置保持账号 ID，追番、观看记录等仍属于原账号。
- 完成注册、补验和重置均不自动登录。重置后所有旧设备会话、其他恢复链接均失效。

## 安全边界

链接使用 256 位随机凭证，只在数据库保存 SHA-256 摘要。注册/补验链接有效 24 小时，重置链接有效 30 分钟，凭证按用途区分且只能使用一次。数据库事务中的唯一 claim 防止重复点击、两个不同恢复链接的并发覆盖，以及密码已改变后继续使用旧链接。登录写入会话前再次校验密码版本，避免与重置竞争时重新签发旧密码会话。

邮件只使用固定配置的站点地址，不采用请求 Host、Origin、转发头或用户传入的回跳地址。凭证放在 URL fragment，确认页加载后立即从地址栏移除，仅保留在组件内存；不发送到页面 HTTP URL，不保存到 localStorage/sessionStorage。GET、邮件扫描器预览、打开页面均不消费凭证，必须显式 POST 确认。

找回和注册请求返回统一提示。生产使用 `waitUntil` 在响应之外投递，已知/未知找回邮箱执行相同的 SQL 路径，避免把邮件服务延迟带入同步响应。请求受现有接口防护和 D1 限流约束：同邮箱跨操作至少间隔 60 秒、每小时最多 5 次，站点每天最多受理 200 次邮件请求；密码变更通知不占上述申请数。邮件 API 失败时删除尚未使用的凭证，只记录无个人信息的 `lingqi_mail_delivery_failed`，不能把请求受理等同于邮件已送达。

原有密码散列算法、HttpOnly/Secure/SameSite 会话、CSRF/Origin 校验、私有数据账号边界保持有效。旧账号不被自动标记成已验证。

## 验证

`check-email-recovery.cjs` 在真实 SQLite 迁移、Web Crypto 和模拟邮件服务上验证注册、哈希/有效期/用途、并发消费、并发重置、旧登录竞争、会话撤销、记录归属、旧账号、配置缺失、失败日志脱敏、地址注入和配额。

`check-email-ui.cjs` 验证先邮箱后密码、手动确认、StrictMode 重放、地址栏清理、密码确认、加载/过期提示、重发冷却和缺配置时已有登录仍可用。旧评论、弹幕和个人库测试改为完整的模拟邮件注册/验证/登录流程，未降低原有权限检查。

本地云浏览器预览连接被拒绝；生产页面验收在部署后进行。未配置真实发信服务前，不能声称已验收收件箱送达或真实跨设备找回。
