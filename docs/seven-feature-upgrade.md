# 别名、播放诊断与搜索下载工具

更新日期：2026-10-22。沿用现有邮箱账户、D1 同步与番剧/播放页。

| 功能 | 入口与行为 |
| --- | --- |
| 番剧别名 | 番剧详情和播放页搜索区。每部最多 16 个，每个最多 120 字，去重并保存在当前用户空间；更新别名不打断当前检测；重新检测时依次尝试个人别名、中文名和原名，最多 4 个检索词。收藏检索也匹配别名。 |
| 低内存播放 | 播放器设置的“缓冲与内存”。自动模式参考浏览器节省流量/慢速网络提示，也可手动选择。HLS 使用更短的前后缓冲和更小的字节目标，改变设置不重载视频、不丢失播放位置。原生 HLS/MP4 的缓存由浏览器管理，参数不是整个页面的内存上限。 |
| 播放诊断 | 播放器下方展开后每秒采样内核、分辨率、缓冲、丢帧和网络状态；关闭停止采样。最近 40 条关键事件只保留在本页，可复制或清空；隐藏签名参数和媒体路径，不上传报告。 |
| 规则测试 | 侧栏“规则测试”，或规则编辑区进入。可选现有规则，或只测试尚未保存的单条 JSON；分阶段查看请求、结果解析、首个结果的分集线路，再选择分集解析。响应以文字显示，不执行源站脚本；解析出媒体地址不等于已验证画面。支持停止和超时。 |
| 批量下载与任务 | 播放页展开“批量下载当前线路”，每批最多 50 集，任务页最多 100 条。逐集解析并准备签名链接，支持暂停准备、取消、重试、删除及刷新恢复，跨标签页通过 Web Locks 串行。准备需要网站保持打开。就绪后用户每次最多发起 3 个文件，由浏览器管理实际保存进度、暂停和取消；本站仅标记“已交给浏览器”，不声称下载完成。任务元数据仅保存在当前浏览器的账户空间。 |
| 搜索快捷语法 | 搜索框支持 `id:`、重复 `tag:`、`sort:`、`season:`、`date:`、`score:`、`rank:`、`weekday:`；提交后映射到高级筛选。季度与上游 Kazumi、本站时间表一致，包含提前一个月开播的日期窗口，例如 2023Q4 为 9 月 1 日至 11 月 30 日。显式 date 区间两端均包含。含语法字段的普通标题可整体加引号，如 `"ID:INVADED"`。不支持的范围、重复条件和日期在发请求前报错。 |
| 收藏检索 | 中文名、原名和个人别名统一规范化匹配；空格分隔的多个词全部匹配。可按追番状态过滤，并按最近添加、名称、评分或首播日期排序，稳定保留同值条目顺序。 |

## 数据与兼容

别名使用现有 `personal_items` 的独立 `aliases` 类型，不创建追番或观看记录，无需新增表迁移。新版使用 `/api/library?version=2`；旧接口不返回别名，旧客户端无法误删新类型。别名沿用账户隔离、版本冲突、删除墓碑、待同步队列和备份导入导出，最多保存 1000 部的别名。

视频不进入 D1 或 R2。浏览器下载沿用已实现的签名附件接口：MP4/WebM 支持源站允许的范围续传；非加密点播 HLS 下载为完整离线 ZIP，不支持 ZIP 中断续传。网页无法观察原生下载是否被浏览器多文件权限拦截，因此任务页明确提示到浏览器下载列表确认。

## 验证

- `check-seven-features.cjs`：真实 SQLite/D1 别名隔离、幂等、墓碑、旧协议兼容，别名找源顺序；快捷语法、日期边界、分页与上游请求；收藏多词检索；缓冲策略、诊断脱敏；真实规则测试分阶段与取消。
- `check-download-queue.cjs`：真实任务代码的顺序准备、账户隔离、跨页锁、失败重试、链接过期、主动批量交接、暂停恢复、取消与移除后迟到响应隔离。
- `check-availability-hook.cjs` 验证别名编辑不重复启动整批检测，显式重测使用最新别名。找源只读接口遇到短暂并发拥堵最多按 Retry-After 等待重试两次；不重试账户/讨论等写操作或频率额度耗尽。
- 线上日志确认取消的 Worker 可能来不及调用流清理，遗留找源并发计数。仅给本已有限时的 source/resolve 增加 60 秒占位过期回收；频率配额不重置，视频/下载长连接不使用此过期策略。安全回归覆盖取消遗留、迟到重复释放不影响新占位、长下载保留并发限制。
- 浏览器验收还发现首次播放前拖动到结尾会被误报为线路无画面；现在对已有有效视频画面的暂停结束保留重播入口，不上报播放成功或写入观看记录；真正缺失视频轨的失败仍保留。
- 原有账户/同步、播放/恢复、筛选、原生与离线下载、安全缓存及完整网站回归继续运行。
