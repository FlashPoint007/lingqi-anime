# 播放线路与莫兰迪界面复查

日期：2026-10-21。基线：v63。以下是实际解析、HTTP Range 取样和 `ffprobe` 初始化信息检查结果，不把目录可用或 HTTP 200 当作浏览器成功播放。

## 实测原因

| 场景 | 证据 | 处理 |
| --- | --- | --- |
| 芙莉莲第二季，稀饭主线 1 | 返回 MP4，630,156,924 字节，视频 HEVC Main / 1920×1080 / yuv420p，音频 AAC。云浏览器出现有声音但视频宽高为 0 的情况。 | 浏览器缺少对应解码能力时，普通代理不会改变编码。保留真实画面确认和有界自动换源，不宣称已转码。 |
| 同集稀饭主线 2、moonci 的两条线路 | 初始文件大小、MP4 头及返回的媒体文件一致；稀饭公开播放签发结果也只有一个候选文件。 | 失败记录同时保留当前集的媒体 URL。另一个源站播放页再次返回这个文件时直接跳过，不再挂载播放器重复黑屏。仅在当前集内有效，手动重试可清除。 |
| 较慢的 MP4 初始化 | 上述 MP4 的 `mdat` 为 628,772,623 字节，`moov` 位于偏移 628,772,659，大小 1,384,265 字节。实测首段取流约 3—7 秒，另一条初始化信息请求发生读取超时。 | 原来固定 12 秒的启动等待不考虑持续收到数据。现为 12 秒空闲超时 + 独立 45 秒总上限；`progress`/元数据事件只延长空闲期限，加载完成和切源取消全部定时器。 |
| akianime 第二季某条 HLS | 解析响应给出媒体地址，但该文件经本站媒体代理明确返回上游 HTTP 404。 | 404/410 文件不再作为未验证直连候选。继续检查其他声明，返回具体失效原因。服务器 401/403 与文件不存在分开，仍允许普通浏览器直连尝试。 |
| giriGiriLove 第二季第 1 集候选 | 文件 310,581,686 字节，初始化信息中视频编码为 H.264 / avc1，1920×1080，音频 AAC；`moov` 在偏移 309,796,573，大小 785,113 字节。 | 找到与上述 HEVC 文件不同的候选，继续用浏览器验收实际播放。 |
| 芙莉莲第一季 MXdm 第 1 集 | 云浏览器实际视频宽高 1280×720，readyState 4，播放时间持续前进。 | 用真实番剧验证正常播放路径，避免只用测试片段验收。 |

取样只用于临时诊断，视频文件不写入数据库。服务访问凭证只发给本站，未提交到源码、文档、浏览器代码或日志。未绕过上游认证、验证码或地域限制。

找源按每源第一条、每源第二条、每源第三条的顺序推进；同一次找源复用已取得的目录，先给其他源机会，避免一个慢源的三条线路耗尽总预算。只有明确包含当前集的道路参与，集数及断点不变。

## 界面

播放页单独使用 `app/watch-theme.css`，暖炭灰 `#222329`、雾蓝 `#aab6c8`、灰藕紫 `#afa0b2`、米白 `#f1ece5`。选中项用灰紫底 `#6b6376`，普通主按钮用蓝灰 `#626d7d`；正文对比度分别约 4.87:1 和 4.56:1。播放头部、侧栏、资源检测、分集、控制栏、进度条、字幕和弹幕设置统一使用这一套颜色。正常画面和原始弹幕颜色不改写。

## 验证

- `check-playback-recovery.cjs`：媒体文件去重的集数隔离、手动重试；持续取流、空闲超时、45 秒总上限和清理。
- `check-player.cjs`：实际错误处理和自动找源跳过不同页面的相同失败文件，继续正确集数与断点。
- `check-review.mjs`：已失效文件、Unicode URL 归一化、后续健康候选、服务器拒绝访问时保留普通浏览器尝试。
- 原有播放器设置、签名媒体、范围请求、限流、字幕、季度编号与生产构建继续检查。

参考：[MDN 视频编码指南](https://developer.mozilla.org/en-US/docs/Web/Media/Guides/Formats/Video_codecs)、[canPlayType](https://developer.mozilla.org/en-US/docs/Web/API/HTMLMediaElement/canPlayType)。不同设备的格式支持应实际检测，不能仅凭浏览器名称或系统推断。
