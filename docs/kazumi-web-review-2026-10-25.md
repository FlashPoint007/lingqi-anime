# Kazumi 对比与用户流程复查（2026-10-25）

本次以本站 v94 为基线，重新读取官方 [Kazumi releases](https://github.com/Predidit/Kazumi/releases) 和 main `7c708fa3f688a1ea709c7c2947bf7aaa13af9558`。最新正式版仍为 2.4.2（2026-10-23）；之后分别是 Linux 包依赖调整和项目结构文档更新，没有新的正式版功能清单。

## 本次迁移与修复

- **片尾续播保护**：上游 `player_playback_controller.dart` / `player_item.dart` 对距结尾五秒内的旧续播记录重播，而不是立即自动下一集。本站在媒体时长可用时执行同样的起点判断，包含超出实际时长的旧记录；普通断点、换线保留进度和定时暂停守卫继续有效。
- **网页播放器轨道选择**：补充 HLS.js 和浏览器原生公开的音轨、独立字幕列表，支持关闭字幕和本地 VTT / SRT。只有媒体确实公开多个音轨才显示音轨选择；硬字幕不能关闭，浏览器未公开的 MKV/ASS 轨道不会伪造为可用。这是本站播放器补齐，不将其写成上游 2.4.2 的新功能。
- **字幕导入竞态**：已用生产 Player 的实际事件处理器复现“移除后慢读取重新加回字幕”，修复前测试失败。移除或手动选择其他字幕会使未完成的导入失效，卸载后同样不创建资源；本地与 HLS/原生字幕互斥，晚到默认轨道不能覆盖明确的关闭选择。
- **字幕文件一致性与键盘操作**：经过校验的 VTT 和 SRT 都使用规范化文本和 `text/vtt` Blob，避免原文件 MIME、BOM/换行差异。选择文件后立即清空输入以便重选；导入入口改为键盘可访问的按钮。
- **原生HLS拒绝后的内核回退**：发布验收中标准HLS样例被浏览器报为媒体格式不可用，原逻辑直接判定源失败。增加一次HLS.js回退，保留现有原生优先策略；回退失败再走现有恢复流程，不循环重试。生产Player事件测试先复现失败，再验证回退后确认画面及再次失败仅报告一次；不把这一兼容性缺口断言为所有第三方源失败的原因。
- **深链接资料占位误用于找源**：浏览器快速返回详情并播放直链时，资料仍为“正在读取番剧…”，占位标题可能进入播放器和17个源的检索。直链入口现在等待真实资料，播放函数也校验占位状态；源检测对详情及播放器均过滤占位对象，避免写入无意义的未匹配结果。

## 本轮检查

代码审查覆盖播放器、逐集记录与续播、查源与恢复、客户端搜索/季度缓存、服务端缓存/限流及 API 错误处理。全量 TypeScript 与 36 个回归脚本共 **37 项通过**；增加生产轨道控制器测试，覆盖 HLS/原生切换、导入互斥、晚到默认轨道、失效选择、不支持接口和监听释放。已有 SQLite/D1、邮箱/规则、下载与安全检查也通过。没有用这些模拟 API 分支冒充 Safari/iPhone 真机测试。

发布前云浏览器验证第二季搜索返回五个相关条目、详情显示29—38集、17个源的粗检及错误原因、讨论面板。托管预览被平台 `/site` 服务占用，不能启动本 checkout 的预览；不终止平台服务，使用正式发布后的浏览器验收补充。第三方源403/验证/520等错误仍保留真实提示，目录存在不视为播放成功。

## 剩余差异与取舍

| 功能 | 处理 |
| --- | --- |
| Bangumi OAuth 收藏、评分、吐槽同步 | 需本站 OAuth 应用和回调、令牌保护及同步冲突方案；不复用 Kazumi 身份。本站邮箱/D1同步不等同于此功能。 |
| ASS/SSA 高级排版、任意封装轨道 | 本次提供浏览器/HLS实际可用的轨道及VTT/SRT；完整ASS需要渲染器、字体、WASM与性能评估，保留缺口。 |
| SyncPlay 一起看 | 上游原生TCP服务不能直接用于网页；保留待建设的鉴权房间服务。 |
| WebDAV、外部播放器 | 已有D1个人数据、离线库及浏览器下载；另接WebDAV需跨域和凭证设计，暂不添加不完整入口。 |
| 原生DLNA、系统解码/ECH、系统亮度和可靠后台运行 | 浏览器不能提供等价控制，不添加无效开关；继续使用支持设备上的Cast/AirPlay/画中画和网页画面亮度。 |
