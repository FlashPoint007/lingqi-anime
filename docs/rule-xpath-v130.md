# TvTFun XPath 网页兼容修复（v130，2026-11-11）

v129 上线验收时，云浏览器再次复现 TvTFun 搜索成功（3 个结果），分集线路阶段报错：`//ol[@class*='tvt-watch-episodes']` 不是浏览器支持的 XPath。

这是上游规则中使用的非标准属性子串语法与浏览器原生 XPath 1.0 的差异，不是规则未同步。网页解析入口将引号外的 `@属性 *= 字符串` 转换为 `contains(@属性, 字符串)`，已有合法 XPath、字符串内容、章节相对路径保持原语义。无需修改上游原始规则快照，后续自动同步仍能工作。

本轮回归检查属性名、引号、多个谓词与字符串保护，以及传给真实解析入口的表达式。上线后通过站内规则测试页检查真实响应和浏览器 DOMParser/Document.evaluate；目录解析通过不等于视频一定可播放。
