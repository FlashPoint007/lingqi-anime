# 上游对比与全流程兼容性复查（2026-10-24）

本站基准 v92。核对上游最新正式版 [Kazumi 2.4.2](https://github.com/Predidit/Kazumi/releases/tag/2.4.2)（2026-10-23 发布）及 main `1e3e111553b74c07f4412fa8a0e7959821caa789`。正式版后的唯一提交为 Linux Debian 打包依赖，不是网页功能；2.4.2 的规则镜像已经在本站 v91 接入。本次没有虚构更高版本。

## 本次补齐

上游已有[简繁转换选项](https://github.com/Predidit/Kazumi/blob/1e3e111553b74c07f4412fa8a0e7959821caa789/lib/pages/settings/danmaku/danmaku_ch_convert_tile.dart)。本站新增“不转换 / 转为简体 / 转为繁体”，作用于公开来源、本站和本地导入的显示文字。采用 opencc-js 1.4.2 方向词典，随本站打包，只有启用转换且有弹幕时才加载对应方向，不依赖运行时第三方 CDN；默认不增加首页和播放器的词典请求。

仅转换本机显示，保留原始缓存、发送内容、时间、类型、颜色和来源。屏蔽规则同时应用于原文与转换后的文字，转换后的重复弹幕仍合并。切换分集、开关、转换方向或卸载后，旧的异步结果不能覆盖当前弹幕；加载失败仍可观看并显示原文，可以切换重试。偏好沿用 `danmaku:0` 的 D1 账号空间、冲突检查与离线待上传队列，不新增数据库结构；未登录保存在本机。

## 修复

1. **旧浏览器取消接口缺失**：客户端已兼容 `AbortSignal.any` / `timeout`，但排除已看搜索、规则测试、离线下载及下载任务仍直接调用 `throwIfAborted`。新增统一检查，不要求此原生方法；取消仍保留原因，没有原因时使用 AbortError。
2. **iPhone 原生全屏状态**：原先只订阅标准 fullscreenchange，也未处理 webkitExitFullscreen。现在监听进入/退出事件并识别原生全屏；标准请求失败后仍尝试 iPhone 视频全屏，最后才使用网页全屏。
3. **Safari 画中画及退出**：支持标准和 WebKit presentation mode，重复点击可以退出；未加载与设备不支持分别给出提示，不错误地只要求等待加载。
4. **移动端音量被拒绝或忽略**：音量滑块与触屏手势共用安全设置，确认设备实际接受后才显示成功；失败提示使用系统音量键，手势不会抛出异常。
5. **续季编号显示**：线上第二季实际播放第29集，源站标题为“第01集”，详情续播和历史会显示错误的本地编号。现在详情、历史与播放标题统一使用已确认的规范集数，保留真正的集名，不显示“第29集 · 第01集”两个冲突编号。

6. **发布验收中的连续超时**：v93 发布后首次搜索及重试均约20秒超时；运行日志显示元数据请求被取消、其他规则/账号接口仍200，未记录崩溃。进一步发现限流队列和缓存共享任务缺少租约，数据库清理也阻塞响应。补充限流检查2秒截止、队列4秒租约和晚回调隔离；检查超时返回503，不授予未验证额度。缓存读写各800毫秒截止，上游查询一般16秒、季度40秒，任务保留于 waitUntil 并可过期清理；清理不阻塞用户，晚到旧写入不能覆盖较新记录。不能仅凭取消日志断言所有超时均来自同一原因；模拟取消/冻结、存储不返回和迟到清理已可稳定验证这些缺口。修复随 v94 上线再验收。

## 本轮检查和边界

- 云浏览器从首页搜索芙莉莲第二季，详情目录29—38，自动找源经过无画面/超时线路后恢复到 akianime 线路2，确认真实1920×1080画面；暂停退出后本机逐集进度保留，追番“想看”、检索和列表布局可操作。
- 运行全套目录、季度缓存、源检测竞态、解析/恢复、播放器、下载续传、规则、安全、评论与本站弹幕、邮箱账号及 SQLite/D1 同步回归和 TypeScript 检查，并执行生产构建。最终共36项检查（含类型检查）通过。
- 新增 `check-compatibility-and-conversion.cjs` 使用实际 OpenCC 词典、生产转换 Hook、库偏好验证器、筛选搜索/规则测试、原生全屏/画中画适配和真实触屏事件处理器，覆盖延迟/失败/取消/切换、旧接口缺失、忽略或拒绝音量、全屏回退。`check-cache-timeouts.cjs` 执行生产限流与缓存代码，模拟读取/写入/上游/清理永不返回、请求取消后冻结、旧任务晚返回，以及实际SQLite防止旧写覆盖。`check-library.cjs` 通过实际迁移 SQLite/D1 写入并重新读取转换偏好；`check-player.cjs` 覆盖续季展示编号。
- 本轮云浏览器为 Chromium；没有把 Safari/iPhone 的 API 分支回归描述为真机验收。硬件投屏、WebGPU 与系统后台能力仍需要对应设备。内部预览端口被平台服务占用，不能启动本次 checkout 的独立预览；使用正式发布后浏览器验收补充，代码测试不替代真机结果。
- 第三方源仍可能需要验证、超时、返回404/502或不支持的编码。找到目录和取得媒体地址不等于真正播放；本站保留真实画面确认和自动恢复，不宣称所有源都可用。
