| 上游能力 | 本站实现与边界 |

## 确认并修复的问题

- 第 0 集：播放器允许第 0 集，但逐集进度清理拒绝 `0`，导致特别篇进度、逐集统计和同步丢失。现在保留规范键 `0`，仍拒绝负数、非有限数和 `00` 等非规范键。
- 源选择错位：原本保存规则数组下标，上游同步新增、移除或排序后可能指向另一源。改为保存规则名，下标只从当前规则计算；旧异步回调也从自己对应的旧数组提取规则名。所选规则消失或停用时取消源搜索、清空旧目录并提示重新选择；正在播放的媒体保留。下一集在没有有效源选择时进入自动找源。
- 个人空间加载：观看记录的继续播放、逐集播放及删除按钮在账号空间尚未就绪时停用，避免在切换账号途中操作旧列表。
- 续播状态回退：云浏览器复现续播已解码画面后，晚返回的分集目录或尚在排队的资源检测把“已播放”改回“有分集”。检测版本在整个队列开始时记录，后续收到手动播放结果的源不再启动旧检测；手动目录回报仅补充分集信息，不覆盖已有成功或失败的播放结果。显式重新检测仍可更新状态。回归使用生产的三路并发调度器，覆盖检测开始前已有播放结果的第四个源。

## 仍有差异与是否适合网页

| 能力 | 建议 |
| --- | --- |
| Bangumi OAuth 收藏、评分与吐槽同步 | 适合后续独立接入，需要申请本站 OAuth 应用、回调地址、令牌管理和冲突策略。本站邮箱 / D1 账号同步不是 Bangumi 账号同步。 |
| 弹幕繁简转换 | 适合后续提供可选转换；目前有来源、关键词、正则、重复、长度、类型屏蔽和 D1 偏好同步，尚无繁简转换。 |
| ASS / SSA 字幕、音轨选择 | 字幕渲染可单独评估性能和字体；任意音轨、解码器及嵌入字幕受网页播放器与媒体封装支持限制。已有本机 VTT / SRT。 |
| 一起看 / SyncPlay | 需要独立房间服务与身份权限、WebSocket 同步协议，不能直接搬运原生 TCP 客户端。 |
| WebDAV / 外部播放器 | 优先级较低：本站已有 D1 跨设备同步、备份、站内离线库及浏览器文件下载。WebDAV 需处理跨域、凭证保管和格式兼容；系统播放器调起需浏览器与设备配合。 |
| 原生 DLNA、系统亮度 / 解码器 / 后台管理 | 不添加网页无法兑现的开关；已有浏览器支持的 Cast、AirPlay、画中画。 |
| ECH 传输与系统代理 | 上游属于原生网络传输层；网页 / Workers 不提供相同控制接口。本轮仅适配官方 HTTPS 镜像与故障恢复，不声称实现 ECH。 |
| 弹幕发表 | 本站已有邮箱账号发送、预览、本人撤回和 D1 存储。仅进入本站弹幕库，不冒充向 BiliBili / Gamer / 弹弹play 发表；外部抓取仍受上游访问和授权凭证约束。 |
