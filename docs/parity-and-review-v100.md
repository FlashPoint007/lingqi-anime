## 本轮适配

| 能力 | 本站处理 |
| --- | --- |
| 默认播放倍速 | 对照[上游播放设置](https://github.com/Predidit/Kazumi/blob/7c708fa3f688a1ea709c7c2947bf7aaa13af9558/lib/pages/settings/player_settings.dart)，将0.5—2×扩至0.25—3×、每档0.25。保留原有长按临时倍速，临时操作不覆盖常用倍速。支持旧`kw-player-speed`迁移；备份导出不要求先打开播放器才能读取旧值。 |

| 图片链接识别 | 对照[上游搜图页](https://github.com/Predidit/Kazumi/blob/7c708fa3f688a1ea709c7c2947bf7aaa13af9558/lib/pages/search/image_search_page.dart)，增加公开HTTPS链接输入。填写和切换方式不会发起图片请求；点击识别后由浏览器把链接直接交给trace.moe。本站服务器不抓取该图片。沿用公开URL校验，拒绝私网IP、内部域名、账号凭证及非HTTPS地址。 |
| 候选片段预览 | 对照[上游搜图模型](https://github.com/Predidit/Kazumi/blob/7c708fa3f688a1ea709c7c2947bf7aaa13af9558/lib/modules/search/image_search_module.dart)，允许显式点击后播放一个候选片段。只接纳trace.moe官方媒体主机的预览路径，保留原签名，不拼造媒体链接。换候选、关闭面板、改输入后移除旧视频；失败或过期提示重新识别，仍可用标题找片。 |

识别接口依据[官方API文档](https://github.com/soruly/trace.moe-api/blob/0bc222e8e438fd01e8087618b044ff4831569c21/docs/docs.md)。不将候选预览视为完整视频资源。

## 修复的问题

1. 图片识别只读取旧`episode`字段，会丢失新接口`episode_start`/`episode_end`以及旧接口的集数数组。现在显示单集、范围和列表，继续过滤不合法数据和成人/分级未知候选。
2. 原播放器换集或换源重新挂载时音量回到100%、静音丢失。恢复本机设置，避免突然变响；设备拒绝调音量时保留系统音量提示。
3. 音量为0时，“取消静音”和M键只翻转muted，仍然无声。工具栏和键盘现在共用逻辑，恢复上次非零音量；0音量在备份中按静音保存，同时保留可恢复的音量。
4. 常用倍速存在独立旧键中，个人备份遗漏它。现在统一校验、导出和恢复，并兼容旧键。设备或媒体在元数据加载后才拒绝某个倍速时回退实际可用值，避免异常中断播放。
5. 发布验收补修：滑块原先等待浏览器异步`volumechange`才更新受控输入，快速连续按键时可能被旧状态回退而少走几档。现在在设备确认接受后立即更新显示与记忆，后到的相同事件不再重复写设置。生产组件测试先复现0.5→0.25仍显示0.5，再验证即时反馈。
6. 找片全流程补修：自动源匹配原先移除全部标点，会把仅以重复`?`/`!`区分的续作当成同作。现在保留这类标题标记进行匹配，兼容全角/半角与显式用户别名；仅有不同季度候选时留为“待确认”。测试验证第二季不会读取同为12集的第一季目录。线上实际播放出1080p画面和弹幕，属于抽查一集，不代表所有第三方线路可播。

## 仍未对齐与取舍

| 能力 | 结论 |
| --- | --- |
| Bangumi OAuth收藏、评分、吐槽同步 | 适合后续独立项目，需要本站OAuth应用、回调、令牌保护及冲突规则；邮箱/D1同步不等于此能力。 |
| ASS/SSA完整字幕排版、任意封装轨道 | 有价值，但需渲染器/WASM/字体与低内存验证。现有VTT/SRT、HLS及浏览器公开轨道保持可用，不提供无法兑现的开关。 |
| SyncPlay一起看 | 需有权限的房间服务、时钟同步和断线恢复，不能直接复制原生TCP客户端。 |
| WebDAV、外部播放器 | 已有D1、备份、离线库与浏览器下载；另接需跨域凭证和设备协议设计，本轮不添加空入口。 |
| 原生DLNA、系统解码/ECH、可靠后台任务 | 浏览器不能等价控制。继续使用受支持的Cast/AirPlay/画中画和HTTPS规则镜像，不声称完整对齐原生能力。 |
