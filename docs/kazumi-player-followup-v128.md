- [编辑弹幕时暂停](https://github.com/Predidit/Kazumi/commit/9a20a019c0457683adc68bf01e5c3e49696ffcde)：上游通过实际定时到期事件撤销编辑器的恢复资格。本站已有编辑暂停、手动播放 / 换源 / 退出后的保护，但只在关闭编辑器时检查定时器的当前状态，遗漏了到期之后又取消限制的情况。

## 修复

复现路径：播放中打开弹幕编辑器并自动暂停 → 定时暂停实际到期 → 取消定时限制 → 关闭编辑器。原实现会恢复那次旧的编辑暂停，导致用户没有点击播放也继续播放；发送请求晚返回成功时也可能触发同样行为。

现在实际到期时同步撤销该视频上所有编辑器持有的恢复资格，取消 / 重设定时器不能复活旧资格。按视频实例隔离，编辑器卸载时解除注册；正常关闭编辑器仍恢复自己造成的暂停，提前取消尚未到期的定时器也保留原有行为。用户仍可显式点击播放。

## 验证

扩展 `check-danmaku-composer.cjs`，从生产 WatchPage 提取实际到期回调，结合真实定时器和暂停控制器复现基线的意外 play 调用。修正后覆盖到期后取消、视频实例隔离、提前取消、实际编辑器关闭和发送请求晚成功，继续覆盖手动暂停、手动播放、切源、后台及卸载保护。全站回归、类型检查、生产构建与浏览器播放验收另按发布流程执行。
