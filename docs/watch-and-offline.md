# 播放、逐集记录、讨论与离线下载

更新日期：2026-10-21。沿用邮箱账户、D1 和现有站点品牌。

## 播放操作

- 画面或快进键按住 450 ms 后临时倍速，松开、失去窗口焦点、取消触点、页面隐藏和卸载时恢复原倍速。可设 1.5/2/2.5/3/4 倍。
- 触屏横向滑动在松开时提交跳转；右侧竖滑调音量，左侧调画面亮度。亮度仅影响本机画面，不修改系统设置；手势可以关闭。
- 播放、快进、后退、全屏、静音、上一集、下一集、截图可自定义单键，拒绝重复分配和输入框中的按键干扰，支持恢复默认。
- 新增固定 4:3；普通视频与 Anime4K 画面保持一致。已有字幕、定时暂停、恢复播放和串行 seek 保留。

## 逐集记录

- `WatchRecord.progresses` 按统一后的集号保存位置、时长、更新时间和是否到达结尾。结束事件或到达 95% 标记到达结尾，不把当前秒数相加当作累计观影时长。
- 沿用 D1 `personal_items` 的账户隔离、版本检查、删除墓碑、持久待同步队列。两个设备更新不同集时，客户端对冲突记录按每集更新时间合并并重试；墓碑不参与自动合并。
- 最近 100 部作品、每部最近 200 集。旧记录仅迁移能够明确识别的最后一集，不凭最高集号补出未记录的历史。备份读取上限扩为 8 MB，兼容原 version 1 JSON。
- 观看记录页可展开逐集进度；播放器选集提示历史位置。切换到之前看过但未到结尾的一集时恢复对应位置；到达结尾的集数重新开始。
- 隐身模式阻止线上和离线播放的新进度保存。已有历史保留。

## 浏览器下载到本地

- 播放页“下载到本地”先检查线路，再通过本站签名附件接口交给浏览器下载管理器。切换剧集或离开页面后不依赖网页 JavaScript；进度、暂停、取消及保存位置由浏览器管理，关闭整个浏览器后的行为取决于浏览器设置。网页只提示已发起请求，不把发起下载当作下载成功。保留原生链接，兼容未自动启动时手动点击。
- MP4/WebM 边读边传，不在客户端生成整部 Blob，也不在服务器内存、D1 或 R2 保存视频。转发有效的 Range/If-Range 与 ETag/Last-Modified，是否可续传取决于源站和签名有效期（8 小时）。中文文件名使用安全清理和 UTF-8 Content-Disposition；拒绝错误网页、空文件、不完整的 206 和截断文件。
- 非加密、已结束且不带独立音轨的 HLS 生成无压缩 ZIP：包含本地 playlist.m3u8、初始化片段、去重的完整分片和 README。解压整个文件夹后使用支持 HLS 的本地播放器打开播放列表，播放无需原站或签名。保留 BYTERANGE/初始化片段引用；不将远程 m3u8 或 ZIP 冒充 MP4。
- ZIP 逐项读取并计算 CRC32，仅保留目录元数据，遵循下载消费速度，取消会中止上游；最多 4096 个资源、4 层清晰度、2 GB 文件包。HLS 文件包不支持续传，网络中断需重新下载。
- 自定义公开 HTTPS 视频直链也经相同地址校验；附件接口只接受服务端有效签名，每次重定向和所有分片重新检查公开地址。准备请求共用解析限流；下载单独限频、限制并发，不挤占播放分片名额。

## 站内离线库

- 仅用户明确点击“保存到站内离线库”后注册 Service Worker。视频分为 2 MB 块写入本机 IndexedDB；D1/R2 不保存视频。当前账户的下载列表与其他账户分开，退出登录不自动删除本机文件。
- 支持可读取的 MP4/WebM，以及非加密、已结束的点播 HLS。HLS 保存完整媒体播放列表、初始化片段和所有视频分片，将地址改为本机路径；断网播放不依赖原站 URL 或过期签名。
- HLS 有三路并发及至少 100 ms 的请求间隔，清晰度嵌套最多 4 层、播放列表最多 4 MB、最多 4096 个资源。暂不支持直播、加密 HLS/DRM 或独立音轨。
- 单集最多 1 GB、每个本机账户最多 100 个下载条目。写入前检查空间并保留余量，拒绝空响应、截断长度和未完整覆盖的 206 响应。读取有超时限制。
- Web Locks 限制跨标签页的同时下载；取消通过 BroadcastChannel 转发。失败先停止并等待所有写入，再清理片段；下载完成后才显示为可离线观看。离开页面会中断站内离线保存，重试需要回播放页重新解析和保存；浏览器原生下载不受此任务锁或页面生命周期控制。
- Service Worker 只缓存固定离线页面及脚本，并从 IndexedDB 流式响应本机媒体和 Range 请求。不会缓存账号 API、讨论 API、服务器渲染首页或其他私人响应。首页导航断网时回退到离线放映室。
- `/offline` 是可收藏的独立断网入口，支持本机列表、播放、拖动、删除和断点。离线进度按设备和账户保存；联网回到本站时合并进原有逐集记录，云端确认前保留待同步标记。
- 清理网站数据或浏览器回收存储会丢失下载；共享设备应手动删除本机媒体。
- HLS 离线播放器随站分发当前依赖的 `hls.light.min.js`，保留 Apache-2.0 许可。

### 静态 HTML 导航兼容

线上初验发现离线页面导航失败。托管默认规则会将 `.html` 重定向到无后缀路径；Service Worker 不能直接向导航返回带有重定向状态的缓存响应。入口统一为 `/offline`，缓存使用规范地址，并重新构造去除旧编码/长度头的 HTML 响应。保留 `/offline.html` 兼容入口，升级离线外壳缓存，不删除本机视频。回归覆盖重定向缓存的首页回退、规范入口及旧入口。

跨页面删除与进度保存使用同一个 IndexedDB 读写事务；删除后到达的保存或确认不会重建已删除下载。播放器不再显示固定默认键位提示，避免自定义键位后误导。讨论分页与接口的 10000 条边界保持一致，避免越界后重复显示上一批数据。
