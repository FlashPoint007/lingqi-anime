# 搜索条件与逐集片源状态复查（v108）

本轮从 v107 继续复查，保留此前观看记录保护、同 ID 详情返回和解析预算修复。

## 修复

1. **普通搜索继承旧的高级条件。** 云浏览器先搜索 `Fate/Zero score:10..10`，再只输入 `Fate/Zero`，仍是空结果，评分条件没有清除。根因是新搜索会重置分类、年份和标签，却仅在使用快捷语法时覆盖高级条件。现在每次提交新搜索都采用本次解析的完整条件；普通标题与空搜索清空旧条件，快捷语法替换旧条件，非法输入仍保留当前结果和条件。高级筛选面板中的显式应用行为保留。
2. **播放结果串到其他集数。** 线上《Fate/Zero》第 1 集实际播放 1920×1080 后，进入第 2 集并立即停止解析，没有视频画面，但 moonci 仍显示“已播放”，说明文字仍属于第 1 集。现在播放成功和失败报告携带集数，当前展示与自动选源只采用同集的播放结果；其他集的结果降回目录层面的“有分集”或“待确认”。保留分集目录与原缓存，不因换集重新扫描全部来源，也不会将未知集数或旧缓存当成当前集已播放。第 0 集单独覆盖。

## 验证

新增 `check-search-source-state.cjs` 执行实际搜索入口、根组件的片源状态绑定、逐集状态转换和真实播放结果报告。覆盖旧条件清理、快捷条件替换、非法输入不覆盖当前搜索、普通含冒号标题、跨集播放/失败状态、未知与第 0 集、缓存不变与目录复用。关键问题先复现失败再修复。

验证采用 TypeScript 与 46 个回归脚本，共 47 项；构建后继续在正式站复验普通搜索恢复、换集停止状态、重试后的真实画面与返回。内部预览此前受环境限制，本轮不将其计为通过。抽查结果不代表所有第三方片源都可播放。
