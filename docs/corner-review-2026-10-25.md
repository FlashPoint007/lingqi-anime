# 入口与异常状态复查（2026-10-25，基线 v98）

本轮继续检查搜索、分享路由、播放选集、账户窗口、备份恢复、复制操作及个人空间切换。没有改动数据库结构、依赖或全站规则。

## 修复

1. **时间表分享入口误选周一**：云浏览器在周日输入 `#calendar`，页面实际展示周一节目。缺少 `day` 的分享链接现按北京时间当天打开；显式 `day=0` 仍表示周一。启动时的选日、页面“今天”标记共用同一个北京时间函数，避免浏览器时区与季度、历史日期不一致。日期按钮增加选中状态，辅助技术能够识别当前星期。
2. **异步备份导入缺少个人空间边界**：等待文件读取期间切换账户后，旧读取仍可能合并追番、历史、别名和偏好到新账户。现在在个人空间加载/切换时更换导入上下文；A→B→A也使旧读取失效，卸载后不再更新页面。连续选择两个备份时，旧文件晚返回不能覆盖或追加到新文件；个人空间尚未读取完成时不开始导入。
3. **复制标题的旧请求覆盖新结果**：连续复制中文名、原名时，较早请求的失败可能在较新请求成功后恢复旧的手动复制框；同一个条目补全标题后也可能恢复占位标题。现在按最新操作及条目标题校验回调，标题变化时清除旧反馈。
4. **选集面板隐去当前源缺少的剧集**：上一轮实播的《夏目友人帐》官方目录13集，当前线路12集。面板现在单独列出目录中未在当前线路收录的剧集，可点击“跨源寻找”；与集数、标题筛选及正倒序联动，保持续季的规范编号。只有点击后才查找其他源，不将缺少的剧集伪装成已找到资源。
