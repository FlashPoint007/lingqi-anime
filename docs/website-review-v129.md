## 修复

1. 发现页完整重置：原先“重置筛选”保留排除已看完/已弃番，且只剩个人排除条件时重置入口消失。现在一起清除个人条件、批次游标，恢复第一页；个人筛选也进入条件摘要。云浏览器已在旧版复现“搜索芙莉莲 → 排除已看完 → 重置后 URL 仍 hideCompleted=1”。
2. 标签排序说明：标签查询实际使用相关度，而原按钮称为播出日期；现在展示实际语义。
3. 批量下载集数身份：原来列表按行号展示、任务却只传 episode.number，普通规则解析出的编号没有传入任务，导致离线弹幕和逐集记录缺少集数。现在解析明确编号并保留季对齐编号，统一用于展示及两种下载队列；SP/OVA/番外/无编号标题不按行号伪造正片编号。
4. 校正旧功能对照文档：公开图片 URL 识别、片段预览和搜索快捷语法已经存在，不再误列为未实现。
